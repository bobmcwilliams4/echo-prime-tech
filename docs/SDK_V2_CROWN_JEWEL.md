## WHAT THE SDK IS

The ECHO PRIME SDK is the unified developer interface to the entire ECHO PRIME
intelligence platform. It wraps 187 Cloudflare Workers, 14 MCP servers, 5,486 AI
engines, 607K doctrine blocks, 312K graph nodes, 29 LLM workers, 12 AI personalities,
and 100K+ indexed code functions into ONE importable package with typed function calls.

Think of it as the Stripe SDK but for an AI intelligence platform. One install,
one API key, one gateway — access to everything.

## THE PROBLEM IT SOLVES

Without the SDK, using ECHO PRIME requires knowing which of 187 cloud worker URLs
to hit for each capability, each worker's unique auth scheme and API shape, how to
chain calls across workers, and internal routing logic between memory systems, engine
runtime, knowledge forge, etc. The SDK eliminates all of that.

A developer writes:
  const result = await echo.engines.query("oilfield drilling optimization")
Instead of manually constructing HTTP requests to worker URLs.
