## Getting Started

### Prerequisites

- Node.js 20+ or Python 3.11+
- Git

### Installation

```bash
git clone https://github.com/ECHO-OMEGA-PRIME/echo-prime-tech.git
cd echo-prime-tech
npm install
```

### Configuration

Copy `.env.example` to `.env` and fill in your API keys and configuration values.

### Development

```bash
npm run dev
```
